# Student Placement Prediction System

## Project Overview
This project uses machine learning to predict student placement status based on academic performance, technical skills, communication skills, and other student-related features.

## Objectives
- Explore and clean student placement data.
- Perform exploratory data analysis (EDA).
- Train and compare multiple machine learning models.
- Evaluate models using accuracy, precision, recall, and F1-score.
- Tune a Random Forest model.
- Create an interactive student placement prediction interface.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Joblib
- IPywidgets

## Machine Learning Models
- Logistic Regression
- Random Forest Classifier
- Linear Support Vector Machine
- K-Nearest Neighbors

## Evaluation
The models are evaluated using accuracy, precision, recall, F1-score, and confusion matrices. Actual results are available in the model comparison output.

## Project Files
- Student_Placement_Prediction_System.ipynb: project notebook
- model_comparison.csv: model evaluation results
- feature_importance.csv: feature importance values
- feature_importance.png: feature importance graph
- confusion_matrices.png: confusion matrix graphs
- student_placement_final_model.pkl: tuned final model

## How to Run
1. Open the notebook in Google Colab.
2. Upload the required dataset.
3. Run the notebook cells in order.
4. Use the interactive form to generate a placement prediction.

## Disclaimer
Predictions are estimates generated by a machine learning model and are not guarantees of actual student placement.
